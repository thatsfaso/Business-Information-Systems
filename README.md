# Patient Treatment in Emergency Departments

Business Information Systems project analyzing patient treatment workflows in emergency departments using process mining and data analytics.

## Description

This project applies business information system methodologies to model and optimize patient flow in emergency departments. It examines triage, initial assessment, treatment planning, and discharge procedures to identify bottlenecks and improvement opportunities.

## Technologies

| Tool | Purpose |
|------|---------|
| Jupyter Notebook | Interactive analysis and documentation |
| Pandas | Data manipulation and analysis |
| Seaborn | Statistical data visualization |
| PM4PY | Process mining and workflow analysis |

## Project Structure

```

```

## Usage

1. Open `BIS Project Fasolino.ipynb` in a Jupyter environment
2. Install required libraries: `pip install pandas seaborn pm4py`
3. Run cells sequentially to view the analysis and visualizations
4. Review the project report for findings and recommendations

## Requirements

- Python 3.x
- Jupyter Notebook
- Pandas, Seaborn, PM4PY
